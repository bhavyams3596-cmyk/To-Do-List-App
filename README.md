# 📝 To-Do List App (Java)

A simple **console-based To-Do List application** built in Java for beginners to practice core Java concepts like ArrayList, Scanner, loops, and OOP (Object-Oriented Programming).

## 📌 Features
- ✅ Add new tasks
- 👀 View all tasks with status (Pending/Completed)
- ✔️ Mark tasks as complete
- 🗑️ Delete tasks
- 🚪 Exit the application anytime

## 🛠️ Tech Stack
- **Language:** Java
- **Concepts Used:** OOP (Classes & Objects), ArrayList, Scanner, Loops, Switch-Case

## 📂 Project Structure
```
TodoListApp.java   → Main application file containing Task class and program logic
```

## ▶️ How to Run

1. Clone this repository
   ```bash
   git clone https://github.com/your-username/todo-list-java.git
   ```
2. Navigate to the project folder
   ```bash
   cd todo-list-java
   ```
3. Compile the Java file
   ```bash
   javac TodoListApp.java
   ```
4. Run the application
   ```bash
   java TodoListApp
   ```

## 📋 Menu Options
```
1. Add Task
2. View Tasks
3. Mark Task as Complete
4. Delete Task
5. Exit
```
